title: Compared to others
---

Choose ForgeTrail when you want phase decisions and the next-session handoff stored with the project. Start with the [continuity example](/docs/continuity) to see the files involved.

This page used to describe other methods' current features. Those descriptions go stale. Use ForgeTrail's own files to decide whether the job fits. Other gated-spec and change-delta tools can still be the right choice for a single change. This page does not claim what they do today.

Optional Catalyst Forge neighbors (FilePress, LocalSlip, LocalHelm, editorial skills, xFacts) sit beside ForgeTrail for specific jobs. They are not required. See the [tools shelf](https://catalystforge.com/tools/).
